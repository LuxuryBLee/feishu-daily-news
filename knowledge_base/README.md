# 🧠 知识库（第二大脑的地基）

这个目录由「每日早报机器人」自动维护，是你个人知识沉淀的源头。

## 结构

```
knowledge_base/
├── archive/            # 人类可读的每日档案（按年份分文件夹）
│   └── 2026/
│       └── 2026-05-29.md   # 当天推送的全部内容 + AI 解读
└── kb.sqlite           # 机器索引（标题/链接/分类/语义向量），供「去重」与「RAG 检索」使用
```

## 它能做什么

1. **语义去重**：新抓到的内容若与最近 45 天推过的太相似，自动跳过，保证“每天都是新东西”。
2. **可搜索历史**：`archive/` 里都是 Markdown，可直接在 GitHub 上浏览、用网页搜索。
3. **RAG 历史衔接**：AI 解读时会参考相关历史条目，能说出“这延续了你之前看过的 XX”。
4. **第二阶段的素材源**：这些档案可被同步进飞书多维表格、或被 Mac mini 上的「第二大脑问答服务」索引。

## 注意

- 该目录由 GitHub Actions 每天自动 `git commit` 更新，请勿手动大改。
- `kb.sqlite` 是二进制索引文件，不用手动编辑。
