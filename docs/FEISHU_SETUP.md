# 📘 飞书接入保姆级教程（第二阶段）

> 本教程面向**完全不懂技术**的你。第一阶段（早报推送 + GitHub 知识库）**不需要**做这些；
> 只有当你想把内容**存进飞书 / 用第二大脑问答**时，才需要按这里操作。

---

## 一、先搞懂三个关键事实（避免踩坑）

1. 你现在的机器人用的是「**自定义机器人 Webhook**」——它只能**单向发消息**，存不了、读不了。
2. 想让东西能**写进飞书、被检索**，必须升级成「**自建应用**」（拿到 App ID / App Secret）。
3. 创建自建应用的前提是账号属于一个「**团队 / 企业**」——好消息：**可以免费创建一个团队**，你自己当管理员即可解锁；**这和你那 69 元 AI 会员是两回事**（会员买的是 AI 额度，不提供开发权限）。

---

## 二、第 0 步：必做且最简单——配置 Semantic Scholar Key（修复“板块空白”）

这一步**强烈建议立刻做**，它能修复“早报某些板块没内容”的老问题。

1. 打开你的 GitHub 仓库 → **Settings** → **Secrets and variables** → **Actions**
2. 点 **New repository secret**
3. Name 填：`S2_API_KEY`，Secret 填你的 Semantic Scholar Key
4. 保存。完成 ✅（机器人下次运行就会用它，不再被限流）

> 同理请确认 `OPENAI_API_KEY`（DeepSeek Key）和 `FEISHU_WEBHOOK` 这两个 secret 也已存在。

---

## 三、创建免费团队 + 自建应用（拿 App ID / Secret）

1. **创建团队**：飞书 App / 网页端 → 头像 → 「管理后台 / 创建团队」，按引导建一个团队（免费版即可）。
2. **进开发者后台**：浏览器打开 <https://open.feishu.cn/app> → 用刚才的账号登录。
3. **创建企业自建应用**：点「创建应用 → 企业自建应用」，填名字（如“我的第二大脑”）和图标。
4. **拿到凭证**：进入应用 →「凭证与基础信息」→ 复制 **App ID** 和 **App Secret**（Secret 只显示一次，存好）。

---

## 四、给应用开权限 + 开机器人能力

在应用管理页：

1. **添加机器人能力**：左侧「应用能力 → 机器人」→ 启用。
2. **申请权限**（左侧「权限管理」搜索并添加）：
   - `im:message`、`im:message:send_as_bot`（发消息/回消息）
   - `bitable:app`（读写多维表格——用于早报存档）
3. **发布版本**：左侧「版本管理与发布」→ 创建版本 → 提交（个人团队通常可自助通过）。
4. **把应用加进一个群**：在飞书里建一个群（如“我的科技早报”）→ 群设置 → 机器人 → 添加你的应用。

---

## 五、建一张多维表格（早报存档库）

1. 在飞书里新建一个「**多维表格**」，建一张表，加这些字段（列）：

   | 字段名 | 类型 |
   |---|---|
   | 标题 | 文本 |
   | 链接 | 超链接 |
   | 分类 | 单选（或文本）|
   | 摘要 | 文本 |
   | 来源 | 文本 |
   | 日期 | 日期 |

2. **拿到表格的两个 ID**（从浏览器地址栏的链接里）：
   - 链接形如 `https://xxx.feishu.cn/base/【app_token】?table=【table_id】&view=...`
   - `base/` 后面那串是 `FEISHU_BITABLE_APP_TOKEN`
   - `table=` 后面那串是 `FEISHU_BITABLE_TABLE_ID`

3. 把多维表格**分享给你的自建应用**（多维表格右上角「…」→ 添加文档应用/协作者，搜索你的应用名）。

---

## 六、把这些填进 GitHub Secrets（启用早报→飞书表格同步）

在仓库 **Settings → Secrets → Actions** 里新增：

| Secret 名 | 值 |
|---|---|
| `FEISHU_APP_ID` | 你的 App ID |
| `FEISHU_APP_SECRET` | 你的 App Secret |
| `FEISHU_BITABLE_APP_TOKEN` | 上面拿到的 app_token |
| `FEISHU_BITABLE_TABLE_ID` | 上面拿到的 table_id |

填好后，机器人每天推送时会**自动把当天内容写进你的多维表格**（没填则自动跳过，不影响推送）。

---

## 七、用第二大脑问答（Mac mini）

把上面的 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / DeepSeek Key 配到 Mac mini 上，
按 [`second_brain/README.md`](../second_brain/README.md) 跑起来即可在飞书里和你的第二大脑对话。
